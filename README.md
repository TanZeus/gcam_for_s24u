# GCam for Samsung Galaxy S24 Ultra

A modded port of Google Camera (GCam) for the Samsung Galaxy S24 Ultra.

## ⚠️ Limitation: Camera ID 2 only

This port **only works with camera ID 2**. Other camera IDs (other lenses, front camera) are not supported and may crash, show a black preview, or produce broken images.

If you switch lenses inside the app and things break, that's expected. Stick to camera ID 2.

## Device

- **Phone:** Samsung Galaxy S24 Ultra
- **Supported camera:** ID 2 only

## Installation

1. Download the APK from this repo (or the Releases page).
2. Allow installs from unknown sources if Android asks.
3. Install the APK.
4. Grant camera, microphone, and storage permissions on first launch.

## Usage

- Open the app. It should start on camera ID 2.
- Don't switch to other lenses / front camera, they aren't supported.

## Known issues

- Only camera ID 2 works.
- Features tied to other lenses (zoom switching, front camera, etc.) won't work.
