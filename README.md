# GCam for Samsung Galaxy S24 Ultra

A modded port of Google Camera (GCam) for the Samsung Galaxy S24 Ultra.

## ⚠️ Limitation: Camera ID 2 only

This port **only works with camera ID 2, which is the main wide lens**. Other camera IDs (ultrawide, telephoto, front camera) are not supported and may crash, show a black preview, or produce broken images.

If you switch lenses inside the app and things break, that's expected. Stick to the main wide lens.

## Device

- **Phone:** Samsung Galaxy S24 Ultra
- **Supported camera:** ID 2 (main wide lens) only

## Installation

1. Download the latest APK from the [Releases page](https://github.com/TanZeus/gcam_for_s24u/releases).
2. Allow installs from unknown sources if Android asks.
3. Install the APK.
4. Grant camera, microphone, and storage permissions on first launch.

## Usage

- Open the app. It should start on the main wide lens (camera ID 2).
- Don't switch to ultrawide, telephoto, or front camera. They aren't supported.

## Known issues

- Only camera ID 2 (main wide lens) works.
- Features tied to other lenses (zoom switching, front camera, etc.) won't work.
